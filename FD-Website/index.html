01 / PROJECT OVERVIEW

Understanding the project

A research-oriented framework for financial fraud detection with unified data processing, training and evaluation pipelines.

Project introduction

Financial fraud detection aims to distinguish suspicious transactions from legitimate activity. This project brings together representative convolutional, spatio-temporal and graph-based approaches so their capabilities can be studied under a common research framework.

Project objectives

  • Study five selected fraud-detection methods.
  • Understand graph and temporal learning approaches.
  • Compare AUC, F1-score and Average Precision (AP).
  • Present inference metrics and benchmark results clearly.
  • Provide an easy-to-follow demonstration interface.

03 / SELECTED METHODS

Five models in this project

The following descriptions summarize the methods named in the project README.

01

MCNN

Convolutional Neural Network approach for credit-card fraud detection. It learns useful patterns from transaction-related input representations.

Convolutional learning
02

STAN

Spatio-temporal attention-based neural network for credit-card fraud detection, designed to consider spatial and temporal relationships.

Spatio-temporal attention
03

STAGN

Graph neural network approach using spatial-temporal attention for fraud detection, capturing relationships among connected entities.

Graph neural network
04

GTAN

Semi-supervised credit-card fraud detection using attribute-driven graph representation to learn from transaction attributes and graph structure.

Attribute-driven graph learning
05

RGTAN

Risk-aware graph representation approach that extends attribute-driven fraud detection by incorporating risk-aware information.

Risk-aware graph learning

Explanation of results

Among the uploaded inference files, STAN has the highest AUC (0.863385) and AP (0.659499). GTAN has the highest F1-score (0.735732). RGTAN has the lowest values across the three reported inference metrics in these files. These observations describe only the supplied inference outputs.

How to read the metrics

  • AUC: measures ranking/discrimination performance across thresholds.
  • F1-score: balances precision and recall.
  • AP: summarizes precision-recall performance.

Metric definitions are general explanations; the numeric results above come from your files.

Project conclusion

This project provides a common research framework for exploring multiple approaches to financial fraud detection. The README benchmark values and local inference values offer two distinct views of model performance. In the supplied inference files, STAN leads in AUC and AP, while GTAN leads in F1-score. A fair model selection should also consider dataset, evaluation setup, class imbalance and the intended application.
